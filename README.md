# Movie Recommender System

## Project Overview

This project is a content-based movie recommendation system that suggests movies similar to a selected movie using textual metadata analysis. The system is built using Natural Language Processing (NLP) techniques for recommendation logic and Streamlit for an interactive web-based frontend.

The application allows users to select a movie title and instantly receive personalized recommendations through a simple and intuitive user interface.

## Recommendation Approach

The system follows a content-based filtering approach, where recommendations are generated by computing similarity between movies based on their metadata rather than user ratings.

Key Features:
- Metadata-driven recommendations
- No dependency on user history or ratings
- Fast and real-time recommendations using precomputed similarity

## Dataset Used

- tmdb_5000_movies.csv
- tmdb_5000_credits.csv

## Features Considered:

- Movie ID
- Title
- Overview
- Genres
- Keywords
- Cast (Top 3)
- Crew (Director)

## System Architecture & Workflow

- Data Loading & Merging
    - Loaded movie and credit datasets using Pandas
    - Merged datasets on movie title

- Data Cleaning & Preprocessing
    - Removed missing and duplicate values
    - Converted stringified lists using ast.literal_eval

- Feature Engineering
    - Extracted genres, keywords, cast, and director
    - Removed spaces for token consistency
    - Combined all textual information into a single tags column

- Text Processing
    - Converted text to lowercase
    - Applied Porter Stemmer for word normalization

- Vectorization
    - Used CountVectorizer (Bag of Words)
    - Limited vocabulary to 5000 most frequent words

- Similarity Computation
    - Calculated cosine similarity between movie vectors

- Frontend Integration
    - Built an interactive UI using Streamlit
    - Enabled movie selection and real-time recommendations

## Frontend (Streamlit)

The frontend is developed using Streamlit, providing:
- Dropdown selection of movie titles
- Instant display of recommended movies
- Clean and user-friendly interface
